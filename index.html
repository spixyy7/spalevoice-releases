What it does

A microphone key for the whole computer

It runs in the tray and stays out of the way until you press the key. There is no window to switch to and nothing to paste.

Types where you are

The transcript goes straight into the focused field. Or to the clipboard, or into a popup first — your choice.

Three languages, one key

Serbian, English and Mandarin. On Auto it writes whichever you actually spoke, in that language's own script.

Knows when you stopped

It cuts at your pauses and sends only speech, so silence is never uploaded and never billed.

Lives on any screen

A small floating bubble shows what it is hearing. Drag it to whichever monitor you like; it stays there.

Remembers what it wrote

A local history of everything dictated, and a running total of what it has cost you this month.

Your key, your account

You paste your own API key. It is saved on this computer and nowhere else, and every charge is on your own account.

Before you install

What this program does and does not do

  • No key is included. The installer ships without any credentials. You enter your own on first run and it is written only to your computer.
  • There is no server in the middle. Audio goes from your machine to the transcription service you picked, and nowhere else. No account, no telemetry, no analytics.
  • The microphone opens only when you press the key. The bubble shows amber whenever it is listening, and nothing is recorded between presses.
  • Updates ask first. It checks for a newer version on its own but downloads nothing until you say yes, and installs only when you close it.
SHA-256 · SpaleVoice-Setup-1.7.0.exe see the release page

To check the file you downloaded is the file that was published, run Get-FileHash SpaleVoice-Setup-1.7.0.exe in PowerShell and compare. They should match exactly.

Windows will warn you. This build is not code-signed — a certificate costs a few hundred dollars a year and this is a tool made for a handful of people. SmartScreen will say “unrecognised app”. Click More info → Run anyway. Verify the hash above first if you would rather be sure.

Getting started

Four minutes, once

  1. Install and open it

    It puts an icon in the tray and asks which language you want the app itself to speak.

  2. Paste an API key

    Make one at openrouter.ai — it works with every model except Scribe, which has its own. The app shows you what each costs before you choose.

  3. Press the key and talk

    Default is Ctrl + Alt + K, changeable. Press once to start, once to stop; or hold it while you speak.
